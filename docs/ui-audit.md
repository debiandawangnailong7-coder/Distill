## 三个访问路径硬约束（理解后续结论的前提）

1. **hover title 只在桌面有效**（`R:84,189,226,329`），触屏不可用。
2. **点击座位预览只在「自己出牌阶段且未选牌、未瞄准」可用**（`I:364-371`）——
   modal/response/旁观/瞄准状态全部不可用。
3. **遮罩层级吃掉入口**：`#modal`(z90) 挡 topbar 日志按钮；`#overlay`(z110) 挡日志与设置
   （开场页说的「随时可 ⚙ 调整」在那一刻不可达）。

另：`legalActions` 只剩 end_turn 时引擎直接结束回合不发请求（`E:758`），
`R:471-474`「没有可打出的牌」是死分支；「自动结束」无反馈。

## 一、按状态的体检（需要什么 / 能否再访问 / 重复几份 / 删除波及）

### 1. 开场页

- 需要：角色技能、身份目标、人数配比、重访时的对局摘要。
- access：技能效果=点击 detail + hover title；身份目标仅 hover；人数配比零展示；
  重访无对局摘要。
- 结论：删 tagline 重复说明；补人数配比与目标常驻；改 access——roleBadge 点击展开，
  overlay 内放设置入口。

### 2a. 出牌阶段·未选牌

- 重复最重：算力 ×2、手牌数 ×3、回合播报 ×4。
- youPanel 的**射程与手牌上限是唯一来源**（删除后 2a/2b 无备用）；
  ≤980px 座位身份/技能被 `CSS:1111` 隐藏后，youPanel 是唯一路径——**只能砍重复字段
  （头像/角色名/技能名），不能整体删除**。
- 缺：剩余指控次数（`attacksThisTurn`/`attacksLeft` 引擎齐备、UI 零引用）、
  不可打原因聚合（现在只靠逐张点击 `I:53-96`）。

### 2b. 已选中一张牌（仅非指向牌会停留）

- 键盘选中**不可用**牌时 prompt 仍承诺「右侧选择用法」而行动条为空——误导性承诺。
- 取消路径 ×4（再点/Esc/空白/按钮），删任一均有备用。

### 2c. 瞄准中

- 距离/射程 ×4（座位徽章、悬停、youPanel、范围线），各有触屏死角。
- 「需 2 声明」「当作指控切换」**仅存在于 hover 提示**，触屏零路径；
  点击座位只会提交，不能预览目标详情（建议长按/双击预览、单击提交）。

### 3-M. modal 选择

- 选项小卡效果被 `CSS:490` 隐藏 + title 触屏无效 → **效果视觉路径为 0**
  （HuggingFace 选牌、弃牌、对决响应尤其需要）。
- 顺序语义为 0；且 `E:788-796` 对普通弃牌也传 `ordered:true`，序号徽章无效。
  Kimi 放回（`E:720-728`，先选的最后摸到）与 STT（`EF:292-304`，第一张先摸）**语义相反**。
- 无通用取消（Esc 被吞，仅带 pass 的请求可放弃）；modal 挡日志。

### 3-R. 防御响应

- `sourceIndex`/`needed`/`remaining` 引擎已下发（`CB:175-186`）但 UI 未用：
  来源座位不高亮、不写「不响应将失去 1 点算力」、不显示自己算力数字、不显示持有声明数。
- 判定替代的成功花色只在选项 label。

### 4. 濒死救援

- **无救援牌的玩家对此状态零感知**（无 chip、无 toast，只有默认隐藏的日志）——最严重缺口。
- 缺：「还差几点能活」「还有谁能救」「救援的阵营含义」（relation 事件未展示）。

### 5. 旁观（对手回合 / AI 思考）

- 回合信息 ×4 可大幅删减（ribbon/turnInfo/phaseInfo/prompt 两两互备）。
- loot、救援、公开牌数量、多数技能**只存在于默认隐藏的日志**——删 toast 即丢失；
  座位技能行的备用（点击预览）在此状态被禁用，窄屏角色名也被隐藏。

### 6. 动画 / 结算瞬间

- 上舞台的只有牌面 +「谁 → 谁」caption；伤害原因、判定用途/成败、公开牌牌面缺失；
  濒死零展示（`dying` 事件 UI 零消费，已核验）。
- 公开牌：TTS/HuggingFace/思维链都是 `reveal` 事件带完整牌面，UI 只 toast 数字；
  `draw.reveal` 分支不可达（全仓无 `reveal:true` 调用，已核验）。

### 7. 终局结算

- 胜负 ×4、你的身份 ×3 可删；**全员身份唯一来源是表格**（删表格=严重丢失）。
- 出局顺序/凶手/死因、日志回看零路径（overlay 挡住日志按钮）。

### 8. 窄屏横切（`(max-width:980px),(max-height:820px)`——矮桌面同样触发）

- 2a：对手 char/skill/role/distance/equip 全 `display:none`，点击预览是唯一备用（仅此状态可用）。
- 状态 5：彻底无备用——对手技能/装备不可查。
- 手牌效果 ≤620 隐藏，触屏无 title——建议 tap/长按浮层替代 display:none。
