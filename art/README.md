## 设计规则

1. **四件套定身份**：发色 + 发型轮廓 + 主色 + 一个标志道具。缺一件就会认不出。
2. **不做复制**：只取母题（鲸尾、羽翼、钢琴键、红围巾），服装与构图自己设计。
3. **豆包阵营区别对待**：非豆包 4 人走动漫立绘 / Q 版 / gaming；豆包与吉祥物走手绘媒介
   （简笔画、油画棒、彩铅），一眼能分开。
4. **游戏内元素不进参考图**：扑克花色、棋盘、骰子只出现在 gaming 组，且必须与手互动。

## 文件

- `prompts.json`：4 个玩家角色 × 立绘 / Q 版 / gaming，豆包阵营 × 3 种手绘媒介。

- `renders/`：出图原档，**不直接入库**，挑定后再压进 `assets/`。

## 用 Qwen 时的调用方式

- 文生图：直接把 `prompt` + `negative` 传给 `qwen-image`。
- 图生图（推荐）：先用立绘抽一张定妆图，之后用 `qwen-image-edit`，指令写成
  「保持人物、发色、服装不变，改为 <动作/景别>」，一次只改一件事。
- 比例：立绘 3:4（896×1152 起），Q 版 1:1，gaming 3:4；豆包阵营统一 1:1 方形贴纸。
